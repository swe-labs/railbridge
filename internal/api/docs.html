Railbridge Documentation

This documentation is for Go, Node.js, Python, and web developers who need to accept Bangladeshi Mobile Financial Services (bKash, Nagad, Rocket), dispatch transactional SMS, and route custom domain inbound emails without managing separate merchant gateway accounts or mailbox servers.

Reader Contract: After reading this guide, you will be able to create payment sessions, verify TrxIDs with atomic row-locking guarantees, dispatch SMS with automatic gateway failover, and inspect dead-letter webhooks.

60-Second Quickstart

Railbridge compiles into a single, zero-dependency static Go binary. Run locally in SQLite WAL sandbox mode:

# Run in local sandbox mode with automatic SQLite WAL migrations
git clone https://github.com/swe-labs/railbridge.git
cd railbridge
go run ./cmd/railbridge -dev

Your local sandbox is provisioned with default test credentials:

  • API Key: rb_test_sandbox_secret_key_12345
  • Device Token: rb_dev_sandbox_device_token_12345
  • Local Port: http://localhost:8080

Official Go Client SDK

Railbridge includes an idiomatic, production-grade Go SDK in package pkg/railbridge:

go get github.com/swe-labs/railbridge/pkg/railbridge

Example: Create Payment Session

package main

import (
    "context"
    "fmt"
    "github.com/swe-labs/railbridge/pkg/railbridge"
)

func main() {
    client := railbridge.NewClient("rb_live_YOUR_KEY", railbridge.WithBaseURL("https://railbridge.alwaysdata.net"))
    
    session, err := client.CreatePaymentSession(context.Background(), railbridge.CreateSessionRequest{
        ExternalReferenceID: "INV-9021",
        AmountMinor:         50000, // 500.00 BDT
        Currency:            "BDT",
        CustomerPhone:       "01712345678",
        ReturnURL:           "https://your-app.com/checkout/complete",
    })
    if err != nil {
        panic(err)
    }

    fmt.Printf("Session ID: %s\nCheckout URL: %s\n", session.ID, session.CheckoutURL)
}

MFS Payment Rail

The MFS rail automates bKash, Nagad, and Rocket verification. When a customer sends funds via Send Money, the Android SIM bridge detects the carrier SMS and matches it against the session.

curl -X POST https://railbridge.alwaysdata.net/v1/payments/sessions \
  -H "Authorization: Bearer rb_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -H "Idempotency-Key: ord_9921_init" \
  -d '{
    "external_reference_id": "ORD-9921",
    "amount_minor": 15000,
    "currency": "BDT",
    "customer_phone": "01712345678",
    "return_url": "https://store.example/success"
  }'

Transactional SMS Rail

Dispatches single or bulk SMS messages with dual-carrier resilience. Primary dispatch routes through Greenweb commercial gateway; if Greenweb returns errors or timeouts, the circuit breaker automatically switches to secondary Android SIM hardware.

curl -X POST https://railbridge.alwaysdata.net/v1/sms/messages \
  -H "Authorization: Bearer rb_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "to": "01812345678",
    "message": "Your one-time passcode is 812903. Do not share this with anyone."
  }'

Inbound Email Routing & Aliases

Create on-the-fly email aliases for your custom domain (e.g., support@swe-labs.com) that route straight to personal Gmail accounts with Sender Rewriting Scheme (SRS) preservation.

curl -X POST https://railbridge.alwaysdata.net/v1/emails/aliases \
  -H "Authorization: Bearer rb_live_YOUR_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "source_address": "billing@yourdomain.com",
    "target_address": "founder@gmail.com"
  }'

Outbox Engine & Dead-Letter Queue (DLQ)

Webhooks are committed in the same database transaction as payment mutations. Retries execute with jittered exponential backoff ($1\text{s}, 2\text{s}, 4\text{s}, 8\text{s}, 16\text{s}, 32\text{s}$). After 6 failed attempts, jobs transition to dead_letter status.

Inspect Dead-Letter Queue

curl -s -H "Authorization: Bearer rb_live_YOUR_KEY" \
  https://railbridge.alwaysdata.net/v1/admin/outbox/dead-letter

Retry Dead-Letter Job

curl -s -X POST -H "Authorization: Bearer rb_live_YOUR_KEY" \
  https://railbridge.alwaysdata.net/v1/admin/outbox/dead-letter/{job_id}/retry
